# Student Performance Dashboard

## Overview
This Power BI dashboard visualizes student performance based on various factors such as gender, parental education, and race/ethnicity. The dashboard provides insights into students' scores in writing, reading, and math.

## Features
- **KPI Cards**: Displays total, writing, reading, and math scores.
- **Filters**: Allows filtering based on roll number and gender.
- **Pie Charts**: Shows score distribution and gender-based math score comparison.
- **Line Chart**: Analyzes writing scores based on parental education level.
- **Bar Chart**: Displays parental education count by race/ethnicity.
- **Data Table**: Lists students with their total scores.

## How to Use
1. Open the Power BI file (`.pbix`).
2. Interact with filters to analyze different student groups.
3. Hover over visual elements to view insights.

## Requirements
- Microsoft Power BI Desktop
- Student performance dataset (loaded in Power BI)
